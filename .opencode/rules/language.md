# Language

Every written artifact in this project must be in **English**, even when the
conversation with the user happens in Portuguese (pt-br) or any other language.

This applies to:

- **Source code**: identifiers (variables, functions, classes, modules, files),
  comments, docstrings, log messages and error messages.
- **Documentation**: README, `docs/`, `AGENTS.md`, rules, skills, config comments.
- **Version control**: commit messages, branch names, PR titles and descriptions.
- Any technical content written into the repository.

Only the live chat with the user may stay in the user's language.
